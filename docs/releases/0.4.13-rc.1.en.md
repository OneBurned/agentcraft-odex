# AgentCraft 0.4.13-rc.1 — Windows prerelease

This is a candidate for trial deployment, not completed stable-release acceptance.
The bundled mod version is 0.4.13; both mod and bridge use protocol 2.

## Features

- New profiles start with an empty team. Multiple Codex and Claude agents have
  separate connections, conversations and configurable supported roles.
- Codex desktop and native CLI transports; separate Claude Code sessions.
- Approved task queues with developer/reviewer assignment, optional automatic
  assignment, correction rounds, explicit no-review tasks and self-review prevention.
- Team desk, workspaces, appearances, custom 64x64 PNG import, personas and phrases.
- RU/EN setup, update and binary rollback wizard with backups and profile preservation.
- Local Git projects; GitHub is optional. No user accounts or tokens are included.

## Requirements and setup

Windows x64; Minecraft Java 26.3; Java 25; Fabric Loader 0.19.5+; Git.
Fabric API 0.161.0+26.3 and Node 24.16.0 are included. Obtain Minecraft, Java,
Fabric Loader and Codex/Claude separately. Use your own accounts, subscriptions
or permitted API/cloud configuration; this package provides no usage credits.

Verify the archive against SHA256SUMS.txt, extract it, read README.en.txt and run
Setup.cmd. Select a separate installation directory and your Fabric profile.
Save your world, close Minecraft and stop the bridge before replacing files.
Run Start-Bridge.cmd from the installed directory. New agents remain disabled
until configured. Starting the task queue requires explicit plan approval.

## Limitations

- **Claude planning for arbitrary teams is not connected yet.** Claude supports
  developer/reviewer roles; combined Claude planner+reviewer needs further work.
  Codex planning uses a separate scoped permit to create drafts.
- Codex desktop integration depends on the installed application's version and
  local interface. Updates may require rebinding; compatibility with every version
  is not claimed. Native Codex CLI is an alternative.
- **A Codex reviewer cannot be technically prevented from editing in every transport.**
  Desktop relies on instructions, not a dedicated read-only sandbox. CLI can use
  read-only mode. The queue validates commit/HEAD and checkout cleanliness, but
  these checks do not replace access control. Grant only necessary permissions.
- Full manual wizard, Minecraft UI, real accounts and migration of the real personal
  team remain unverified. Automated tests simulate model transports. Stable-release
  acceptance still has open work tracked as t52/t53.
- Binary rollback preserves current user data; it does not downgrade data schemas.
  Recovery after a crash at the very end of a transaction may restore the previous
  version. Some connection validation happens after file installation; retry profile
  setup when rejected. Unknown/reused owner PIDs conservatively block operations.
- Never redistribute a used installation, data, workspaces, logs or backups.

## Validation

Baseline A13 passed 883 bridge tests, 91 Java tests and 45 tooling tests. One opt-in
live SDK test was skipped. Public-candidate checks additionally cover removal of
the six PNGs, unchanged mod classes, custom PNG import, installed bridge startup,
queue/migration and final archive checksums. See CHECKS.json and AUDIT.json attached
to this release. The audit detects its known leak patterns; it does not guarantee
detection of every possible secret.
