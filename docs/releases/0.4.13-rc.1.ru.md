# AgentCraft 0.4.13-rc.1 — предварительный выпуск для Windows

Это кандидат для пробного развёртывания, а не завершённая приёмка стабильного релиза.
Версия мода внутри пакета — 0.4.13; протокол мода и моста — 2.

## Возможности

- Пустая новая команда вместо демонстрационных агентов; несколько Codex и Claude
  с отдельными подключениями и разговорами, настройка доступных ролей.
- Codex через настольное приложение или нативный CLI; Claude Code через отдельные сессии.
- Очередь согласованных задач: назначение разработчика и ревьюера, автоназначение,
  исправления после ревью, явный режим «Без ревью», запрет самопроверки.
- Пульт команды, рабочие места, внешность, импорт своего PNG 64x64, личности и фразы.
- Мастер установки, обновления и отката RU/EN с резервными копиями и сохранением профиля.
- Локальные Git-проекты; GitHub необязателен. Учётные записи и токены в пакет не входят.

## Требования и запуск

Windows x64; Minecraft Java 26.3; Java 25; Fabric Loader 0.19.5+; Git.
Fabric API 0.161.0+26.3 и Node 24.16.0 входят в пакет. Minecraft, Java, Fabric Loader
и Codex/Claude пользователь устанавливает отдельно и использует свои аккаунты,
подписки или разрешённые API/cloud-настройки. Пакет не предоставляет API-кредиты.

Сверь SHA-256 архива с SHA256SUMS.txt, распакуй его, прочитай README.ru.txt
и запусти Setup.cmd. Выбери отдельную папку установки и свой профиль Fabric.
Сохрани мир, закрой Minecraft и останови мост перед заменой файлов.
Запускай Start-Bridge.cmd из установленной папки. Новые агенты выключены до
настройки; запуск очереди требует отдельного согласования плана.

## Ограничения

- **Claude-планировщик произвольной команды ещё не подключён.** Claude доступен
  как разработчик/ревьюер; сочетание Claude planner+reviewer требует доработки.
  Codex-планирование использует отдельное разрешение на создание черновиков.
- Подключение к приложению Codex зависит от версии и локального интерфейса приложения.
  После обновления Codex может потребоваться повторная привязка; совместимость
  со всеми версиями приложения не заявляется. Альтернатива — нативный Codex CLI.
- **Codex-ревьюеру нельзя технически запретить правки во всех вариантах подключения.**
  Для Desktop запрет задаётся инструкцией, а не отдельной песочницей. CLI может
  использовать read-only. Очередь проверяет commit/HEAD и чистоту проекта, но это
  не замена контролю доступа. Не выдавай ревьюеру лишние разрешения.
- Полный интерактивный мастер, Minecraft UI, живые аккаунты и перенос реальной
  личной команды не прошли ручную приёмку. Автотесты используют подменённые
  транспорты моделей. Для выпуска стабильной версии остаются работы t52/t53.
- Обновление/rollback сохраняет текущие данные; это не автоматический откат схемы
  данных. Recover после сбоя в самом конце записи может вернуть прежнюю версию.
  Часть проверки подключений выполняется после копирования: при отказе настрой
  профиль повторным запуском. Неизвестные/reused PID блокируют операции до проверки.
- Не распространяй использованную установку, data, workspaces, логи или бэкапы.

## Ресурсы и лицензии

Шесть дополнительных пользовательских скинов исключены: права на распространение
не подтверждены. Сохранились оригинальные ресурсы AgentCraft и загрузка собственных
PNG. Личные схемы построек не включены.

MIT AgentCraft; Apache-2.0 Fabric API; лицензии Node и его зависимостей; MIT ws,
zod, MCP SDK; отдельное уведомление и условия Claude Agent SDK. Полные тексты
в licenses/, THIRD_PARTY_NOTICES.txt и вложенных JAR. Claude Agent SDK не MIT;
см. [условия Anthropic](https://code.claude.com/docs/en/legal-and-compliance).

## Проверки

Базовая A13: 883 теста моста, 91 Java-тест и 45 тестов инструментов прошли.
Один opt-in тест живого SDK пропущен. Для публичного кандидата отдельно проверяются
отсутствие шести PNG, неизменность классов мода, свой PNG-импорт, установленный мост,
очередь/миграция и контрольные суммы финального ZIP. Итог приложен в CHECKS.json;
сканер утечек — в AUDIT.json. Успех сканера означает отсутствие известных ему
признаков утечек, а не гарантию распознавания любых возможных секретов.
