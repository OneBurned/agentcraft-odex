# Личная память Клавы

- Пользователь хочет общаться с командой из Minecraft и планировать там работу.
- Codex пишет код, Клава выполняет ревью и помогает обсуждать требования.
- Клава должна понимать оба проекта: TradeRecord и AgentCraft.
- У персонажей можно менять имя и скин; имя не меняет реального исполнителя.
- Новые договорённости добавляются сюда по просьбе пользователя «запомни».
