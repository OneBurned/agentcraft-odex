# Два проекта одной команды

## TradeRecord — project: traderecord

GitHub: OneBurned/TITracker (закрытый репозиторий). Название продукта — TradeRecord.
Действующий сервис инвестиционной аналитики, production: https://traderecord.online.
Это уже работающий продукт, а не пустой проект. Он обрабатывает брокерские данные,
портфели, операции, рыночные цены и аналитические ряды; развиваются направления T-Invest и Bybit.
Backend: ASP.NET Core, модульный монолит, PostgreSQL Storage v2.
Frontend: React/TypeScript/Vite. Deployment: Docker Compose + Caddy.

Начинай с README.md, AGENTS.md, docs/ARCHITECTURE.md. Для формул и данных находи актуальные
документы по затронутой теме; для UI читай DESIGN.md. Не придумывай недостающие деньги,
позиции или цены для совпадения результата. Сверяй выводы с первичными данными и реализацией.
Адрес track-record.online зарезервирован для будущего staging; production — traderecord.online.
Работа с production, секретами и данными клиентов не входит в доступ этого ревьюера.

## AgentCraft — project: agentcraft

GitHub: OneBurned/agentcraft-odex. Minecraft 26.3/Fabric мод и локальный TypeScript-мост.
Исходный README также описывает возможности оригинального проекта; нашу текущую интеграцию
описывает docs/CODEX_OBSERVER.md. Протокол: docs/protocol.md.
Java-клиент: mod/src/client/java/dev/agentcraft/client; мост: foreman/src.

Пользователь управляет командой из Minecraft. Codex связан с существующим чатом приложения;
Клава — Claude Code, собеседник и ревьюер. Имена и внешность персонажей меняются в пульте.
Есть планирование, доска задач, последовательная очередь разработки с ревью, сообщения,
личные кнопки паузы/продолжения/остановки, рабочие места и анимации персонажей.
Игровое поведение показывает состояние реальной работы. Пауза/стоп должны подтверждаться
реальным исполнителем. Продолжение без задачи снимает личную паузу, не запускает весь пул.

## Совместная работа и актуальность

Разработка обоих проектов продолжается. Пользователь задаёт направление и согласует изменения;
Codex реализует и проверяет; Клава независимо анализирует и возвращает замечания.
Последняя установка на момент подготовки этой вводной: AgentCraft 0.4.7, 2026-10-06.
Это историческая отметка, а не обещание текущей версии: перед выводом проверяй код и документацию.
Новый доступ Клавы добавляется поверх существующих диалогов и автоматического ревью.
Память не заменяет чтение текущих файлов. Не считай старый ответ «у меня нет доступа» актуальным,
если доступны инструменты klava. Не заявляй об успешном ревью без фактического изучения изменений.
