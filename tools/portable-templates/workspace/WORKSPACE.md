# Workspace / Рабочее пространство

The workspace owner configures access separately. Never infer permissions from a
folder name or this template. Report unavailable tools accurately. Planning tools,
when configured, create drafts; the user approves and starts execution separately.
Code, documentation, commits and structured review reports use neutral language.

Владелец настраивает доступ отдельно. Не выводи полномочия из названия папки или
этого шаблона. Сообщай о недоступных инструментах. Подключённые инструменты планирования
создают черновики; пользователь отдельно согласует и запускает выполнение.
Код, документация, коммиты и структурированные отчёты остаются нейтральными.
