AgentCraft — переносимый пакет для Windows

ЭТАП A3 — ОТДЕЛЬНЫЕ ПОДКЛЮЧЕНИЯ АГЕНТОВ
Новый профиль создаёт пустой team.json. Создание и изменение агентов доступны через
инструмент studio.mjs: team.get/create/update/disable/archive/restore. Каждый агент
подключается отдельно через connection.bind/get/check/send/control/unbind/importCodex.
Два Codex или два Claude используют разные разговоры. Очередь и экран настройки команды
будут добавлены на следующих этапах.
Протокол 2: мод, мост и инструменты нужно обновлять вместе.
Прежний пульт действует для старых профилей. Явный перенос пары описан ниже.

Это нейтральная сборка существующего режима наблюдения: Codex выполняет задачи
в подключённом чате настольного приложения или своей CLI-сессии; Claude проверяет изменения.
Произвольная команда настраивается через API; графический мастер ещё не готов.
Входы в аккаунты не включены.

УСТАНОВКА И ЗАПУСК
1. Установи Minecraft Java 26.3, Fabric Loader 0.19.5 или новее и Java 25.
   Понадобятся Git и собственное приложение Codex или нативная Codex CLI с выполненным входом.
   Для ревью нужен установленный Claude Code с собственным входом пользователя.
2. Распакуй весь пакет в отдельную папку. Должен присутствовать PACKAGE-READY.json.
   Не помещай пакет внутрь папки mods. Сохрани мир и закрой игру перед установкой.
3. Запусти Install-Mod.cmd и укажи папку игры выбранного Fabric-профиля.
   Установщик копирует мод и Fabric API; заменённые моды сохраняет в резервной копии.
   Существующие настройки не перезаписываются. Minecraft автоматически не запускается.
4. Запусти Start-Bridge.cmd. Для выбранного Git-проекта вместо него можно выполнить
   из PowerShell в папке пакета:
   .\Start-Bridge.ps1 -Repository <полный-путь-к-своему-репозиторию>
   Мост слушает только 127.0.0.1:7878. Если порт занят, сначала останови другой мост.
5. Создай агента через runtime/node.exe studio.mjs team.create --file agent.json.
   В agent.json: revision из team.get и agent с name, provider (codex/claude),
   roles (массив planner/developer/reviewer), enabled, visible и appearance
   (skin, color в формате #RRGGBB, slim). Поля обязательны.
   Получи ID через runtime/node.exe studio.mjs team.get.
   В выбранном Desktop-чате попроси выполнить Connect-Codex.ps1 -Agent <id>.
   Привязка хранится в data/portable/connections. Двойной щелчок не передаёт ID чата.
   Claude: отдельно подготовь папку с инструкциями, MEMORY.md, access.json и
   conversation.json с существующим sessionId, созданным именно в этой папке.
   connection.bind принимает id, revision, connection: {provider:"claude",
   transport:"claude-code",workspace:"абсолютный путь",sessionId:"UUID"}.
   Отправь JSON через runtime/node.exe studio.mjs connection.bind --file binding.json.
   Open-Agent.ps1 -Agent <id> продолжает разговор в терминале, -Desktop — в Code.
   После закрытия сессии Code используй -Return. Вторая копия разговора не создаётся.
   Для старого профиля без team.json Connect-Codex.ps1 без -Agent сохраняет прежний
   путь перепривязки data/portable/codex-chat.json. Для новой команды -Agent обязателен.
   Повреждение подключения одного агента не отключает остальных. Неактивное сломанное
   подключение можно отвязать через connection.unbind (id и revision), даже в архиве.
6. Запусти свой Fabric-профиль и открой обычный мир одиночной игры.
   В творческом инвентаре AgentCraft возьми пульт, консоль, монитор и Настройщик.
   Сообщение в консоли отправляется выбранному агенту; проверь получателя до Enter.
   Рабочие места назначаются Настройщиком. Черновик плана не запускает работу.
7. Stop-Bridge.cmd останавливает мост этого пакета. Данные появляются в data/portable,
   журнал — в logs. После использования не распространяй эту папку как чистый пакет.

CODEX CLI (АЛЬТЕРНАТИВА DESKTOP)
Установи Codex CLI и выполни вход самостоятельно. Исполняемого файла и входа в пакете нет.
Создай агента Codex, как описано выше. В binding.json укажи id, revision из team.get и:
  "connection": {"provider":"codex", "transport":"codex-cli",
    "workspace":"C:\\Projects\\your-repo", "executable":"C:\\Tools\\codex.exe",
    "sessionId":"ТВОЙ-УНИКАЛЬНЫЙ-UUID", "sandbox":"read-only"}
Подставь настоящие абсолютные пути и UUID, один раз созданный через [guid]::NewGuid().
sessionId — ключ разговора AgentCraft; нативная сессия создаётся при первом сообщении.
Выполни runtime/node.exe studio.mjs connection.bind --file binding.json.
connection.check с JSON-файлом {"id":"ID-АГЕНТА"} проверяет версию, команды и вход
без обращения к модели и изменения проекта.
Выбирай workspace-write вместо read-only, только если агент должен изменять рабочую папку.
Интерактивные подтверждения отключены; обход песочницы и скрипты-обёртки не поддерживаются.
Пауза/Стоп дожидаются завершения своего процесса. Продолжение использует точную сессию.
После сбоя моста самостоятельно заверши уцелевший старый CLI-процесс и повтори проверку.
Один разговор CLI должен иметь одного владельца. Передача через Open-Agent/Desktop
для этого транспорта не поддерживается. Настройки CLI и доверенные хуки продолжают действовать.
Не копируй реквизиты входа в binding.json и не распространяй использованный профиль.
Тесты процессов и проверка входа установленной CLI прошли; ручная проверка двух разговоров
с моделью ещё не выполнена. connection.check не запускает задачу модели.

ПЕРЕНОС СУЩЕСТВУЮЩЕЙ ПАРЫ
Приостанови очередь, заверши/останови активные задачи, закрой Minecraft и останови мост.
Верни общий разговор Claude из терминала/Code. Codex оставь открытым и без активной работы.
Из папки пакета выполни:
  runtime/node.exe migrate-team.mjs apply --profile-dir "D:/AgentCraft/data/observer" --game-dir "D:/Minecraft/Fabric" --codex-binding "D:/AgentCraft/codex-chat.json" --backup-dir "D:/AgentCraft-backups/before-team"
Подставь свои абсолютные пути. Выбери НОВУЮ папку копии вне профиля, игры и папки Claude.
Занятый/непроверенный разговор и активная задача запрещают перенос. Задача модели не запускается.
Symlink/junction и дополнительные настроенные агенты требуют отдельного решения.
Копируются весь профиль, папка Claude, привязка Codex, настройки/скины и метаданные миров
AgentCraft. Два прежних ID, история, ожидающие ответы, приостановленные карточки, личности
и назначения мебели сохраняются. Неиспользуемые стандартные персонажи не добавляются.
Нативная история провайдеров и входы остаются на месте и не копируются.
Старая очередь пары остаётся доступной, сначала на паузе. Состав и роли меняются после
реализации общей очереди; имена, внешность и видимость доступны при незавершённых карточках,
открытых вопросах и работающем диалоге. Выключение требует остановки активной задачи очереди
или ответа Claude. Алиасы codex/claude и all → Codex сохранены. Чистые команды не затрагиваются.
Повтор успешного apply ничего не меняет. Для отката останови работу/игру/мост и верни Claude;
повтори ту же команду с restore вместо apply и ТЕМИ ЖЕ путями. Текущие управляемые данные
сначала сохраняются в before-restore-<UUID>, затем возвращаются исходные байты файлов.
Новые файлы в управляемых папках профиля/Claude/скинов удаляются оттуда, но остаются в копии.
Совместимые старые мост/мод при возврате версии восстанавливаются отдельно.
После прерывания используй restore: защитный файл не даст мосту открыть частичный результат.
Штатный возврат разговора снимает и блокировку умершего владельца game, проверив оба PID.
При отказе доступа/повторном использовании PID защита консервативна. Не завершай процесс только
по записанному номеру. Остановив работу, сверь программу, путь и время старта. Только подтвердив,
что процесс посторонний, скопируй и переименуй устаревший foreman.json/portable.json или соседний
<профиль>.migration-lock.json с суффиксом .stale, затем повтори restore. state/team не меняй.
При неизвестной принадлежности процесса защиту оставь до возможности проверки.
Это не полная копия Minecraft-мира или аккаунтов. Не распространяй данные и резервные копии.

НАСТРОЙКИ И ШАБЛОНЫ
В пульте можно задать имя, внешность, характер и фразы. personas.example.json —
нейтральный пример; запускатель копирует его только для нового профиля без personas.json.
Во вкладке настроек укажи командную версию Claude Code и проверь свой вход для ревью.
Не выбирай исполняемый файл графического приложения вместо Claude Code.
workspace-template содержит нейтральные инструкции, а не готовое подключение Claude.
PROJECTS.md заполняется своими проектами; NOTES.example.md — пустая заготовка заметок.
При отдельной настройке рабочего пространства её можно скопировать как MEMORY.md.
Само копирование шаблонов не выдаёт доступа и не включает общий разговор/планирование.

СВОЙ СКИН PNG
Пульт → «Внешность» → выбери агента → «Загрузить PNG…».
Укажи полный путь к настоящему PNG 64×64, размером не больше 512 КиБ.
Нажми «Применить»; выбери обычные или тонкие руки и отображение внешнего слоя.
Файл копируется в config/agentcraft-skins папки игры под именем SHA-256.png;
исходный PNG можно убрать после импорта. Выбор сохраняется в config/agentcraft-studio.json.
Пользовательский импорт требует 64×64. Для некоторых встроенных скинов 64×32
есть отдельное преобразование старого формата; оно не распространяется на импорт.
Шесть дополнительных встроенных скинов названы «Скин 1»…«Скин 6».
Перед публичной публикацией пользователь должен подтвердить права: см. SOURCES.txt.

ПОСТРОЙКИ
Личных построек в обычном пакете нет. Свои .schem помещай в
config/agentcraft/buildings папки игры. /agentcraft preview <имя> показывает объём
и запоминает центр; отойди за границы и введи /agentcraft place <имя>.
Весь объём, включая воздух схемы, заменяет блоки мира. Сначала сохрани резервную копию мира.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
Сборщик проверяет содержимое пакета, включая вложенные JAR, до отметки готовности.
Личные пути, проекты, переписки, память и аккаунты в исходную поставку не входят.
Лицензии сторонних компонентов сохраняются без изменений, включая авторские контакты.
Сборка и проверка импорта PNG не заменяют проверку отображения в самой игре.
При потере связи статусы не являются подтверждением завершения задачи.
Разрешения и возможности конкретного провайдера зависят от его собственного приложения.
