AgentCraft — переносимый пакет для Windows

ЭТАП A2 — МОДЕЛЬ КОМАНДЫ
Новый профиль создаёт пустой team.json. Создание и изменение агентов доступны через
инструмент studio.mjs: team.get/create/update/disable/archive/restore. Подключения
новых агентов, очередь и экран настройки команды будут добавлены на следующих этапах.
Протокол 2: мод, мост и инструменты нужно обновлять вместе.
Описанные ниже чат, пульт и подключение действуют только для существующих профилей
со старой командой; это не инструкция подключения новой команды. Перенос — отдельный этап.

Это нейтральная сборка существующего режима наблюдения: Codex выполняет задачи
в подключённом чате настольного приложения, Claude может проверять изменения.
Произвольная команда и мастер её настройки — отдельные этапы разработки;
этот пакет пока не заявляет их готовность. Входы в аккаунты не включены.

УСТАНОВКА И ЗАПУСК
1. Установи Minecraft Java 26.3, Fabric Loader 0.19.5 или новее и Java 25.
   Понадобятся Git и собственное настольное приложение Codex с выполненным входом.
   Для ревью нужен установленный Claude Code с собственным входом пользователя.
2. Распакуй весь пакет в отдельную папку. Должен присутствовать PACKAGE-READY.json.
   Не помещай пакет внутрь папки mods. Сохрани мир и закрой игру перед установкой.
3. Запусти Install-Mod.cmd и укажи папку игры выбранного Fabric-профиля.
   Установщик копирует мод и Fabric API; заменённые моды сохраняет в резервной копии.
   Существующие настройки не перезаписываются. Minecraft автоматически не запускается.
4. В выбранном чате Codex попроси подключить именно этот чат: выполнить
   Connect-Codex.ps1 из папки пакета в окружении этого чата.
   Самостоятельный запуск двойным щелчком не имеет идентификатора чата.
   Привязка записывается локально в data/portable/codex-chat.json.
5. Запусти Start-Bridge.cmd. Для выбранного Git-проекта вместо него можно выполнить
   из PowerShell в папке пакета:
   .\Start-Bridge.ps1 -Repository <полный-путь-к-своему-репозиторию>
   Мост слушает только 127.0.0.1:7878. Если порт занят, сначала останови другой мост.
6. Запусти свой Fabric-профиль и открой обычный мир одиночной игры.
   В творческом инвентаре AgentCraft возьми пульт, консоль, монитор и Настройщик.
   Сообщение в консоли отправляется выбранному агенту; проверь получателя до Enter.
   Рабочие места назначаются Настройщиком. Черновик плана не запускает работу.
7. Stop-Bridge.cmd останавливает мост этого пакета. Данные появляются в data/portable,
   журнал — в logs. После использования не распространяй эту папку как чистый пакет.

НАСТРОЙКИ И ШАБЛОНЫ
В пульте можно задать имя, внешность, характер и фразы. personas.example.json —
нейтральный пример; запускатель копирует его только для нового профиля без personas.json.
Во вкладке настроек укажи командную версию Claude Code и проверь свой вход для ревью.
Не выбирай исполняемый файл графического приложения вместо Claude Code.
workspace-template содержит нейтральные инструкции, а не готовое подключение Claude.
PROJECTS.md заполняется своими проектами; NOTES.example.md — пустая заготовка заметок.
При отдельной настройке рабочего пространства её можно скопировать как MEMORY.md.
Само копирование шаблонов не выдаёт доступа и не включает общий разговор/планирование.

СВОЙ СКИН PNG
Пульт → «Внешность» → выбери агента → «Загрузить PNG…».
Укажи полный путь к настоящему PNG 64×64, размером не больше 512 КиБ.
Нажми «Применить»; выбери обычные или тонкие руки и отображение внешнего слоя.
Файл копируется в config/agentcraft-skins папки игры под именем SHA-256.png;
исходный PNG можно убрать после импорта. Выбор сохраняется в config/agentcraft-studio.json.
Пользовательский импорт требует 64×64. Для некоторых встроенных скинов 64×32
есть отдельное преобразование старого формата; оно не распространяется на импорт.
Шесть дополнительных встроенных скинов названы «Скин 1»…«Скин 6».
Перед публичной публикацией пользователь должен подтвердить права: см. SOURCES.txt.

ПОСТРОЙКИ
Личных построек в обычном пакете нет. Свои .schem помещай в
config/agentcraft/buildings папки игры. /agentcraft preview <имя> показывает объём
и запоминает центр; отойди за границы и введи /agentcraft place <имя>.
Весь объём, включая воздух схемы, заменяет блоки мира. Сначала сохрани резервную копию мира.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
Сборщик проверяет содержимое пакета, включая вложенные JAR, до отметки готовности.
Личные пути, проекты, переписки, память и аккаунты в исходную поставку не входят.
Лицензии сторонних компонентов сохраняются без изменений, включая авторские контакты.
Сборка и проверка импорта PNG не заменяют проверку отображения в самой игре.
При потере связи статусы не являются подтверждением завершения задачи.
Разрешения и возможности конкретного провайдера зависят от его собственного приложения.
