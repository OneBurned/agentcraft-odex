AgentCraft Codex 0.2.0 — Windows, Minecraft Java 26.3

УСТАНОВКА
1. В Minecraft Launcher создай профиль Minecraft 26.3 с Fabric Loader 0.19.5 или новее.
   Для игры нужна Java 25. Проверена Oracle Java 25.0.2; она уже установлена на этом ПК:
   C:\Program Files\Java\jdk-25.0.2\bin\javaw.exe
   Выбери отдельную папку игры для этого профиля.
   Fabric Loader: https://fabricmc.net/use/installer/
2. Полностью распакуй этот архив в постоянную папку. Запусти Install-Mod.cmd и укажи
   папку игры выбранного профиля. Скопируются AgentCraft и подходящий Fabric API.
   Установщик не ставит сам Minecraft, Java или Fabric Loader.
   Старые версии этих двух модов сохраняются в agentcraft-backups; другие моды не меняются.
3. Запусти Start-Bridge.cmd, затем Minecraft через обычный лаунчер. Открой свой одиночный мир.
   Для настройки рабочего места включи творческий режим. Обязательной студии и автопостройки нет.
   Node входит в архив. Установка Node/npm, Claude или ключей API не требуется.

КАК ОБУСТРОИТЬ CODEX
В творческом инвентаре открой вкладку AgentCraft, возьми Настройщик, Монитор,
Доску задач, Консоль и при желании Индикатор состояния.

Стол и кресло строй из любых обычных блоков. Настройщиком отметь место, где должен
находиться Codex: ПКМ по свободному полу или по креслу из ступеньки.
По умолчанию выбрано «Рабочее место» — его нужно отметить первым.
Shift + ПКМ переключает назначение: чтение, проверки, консоль, ревью, планирование,
отдых, ожидание ответа. Затем ПКМ по полу/креслу задаёт место выбранной зоны.
Для положения на полу Codex смотрит в ту же сторону, что и ты; на кресле — вперёд от спинки.

Поставь монитор, доску и консоль обычным способом. Мониторы и индикаторы без привязки
подключаются к Codex в течение секунды в пределах 32 блоков от рабочего места,
по высоте — 16. Доска расширяется соседними панелями; все панели должны смотреть в одну сторону.
Оставь проходы между зонами и место сбоку от кресел. Многоэтажные зоны требуют лестниц.
Перенос стола/кресла: отметь новое место Настройщиком. Экраны можно ломать и ставить заново.
Необязательные зоны, пока не назначены, используют основное рабочее место.

Команды для точного выбора:
/agentcraft workspace desk
/agentcraft workspace library
/agentcraft workspace testbench
/agentcraft workspace terminal
/agentcraft workspace mergestation
/agentcraft workspace meeting
/agentcraft workspace lounge
/agentcraft workspace user
Команда отмечает блок под прицелом не дальше 8 блоков.
/agentcraft workspace remove lounge — убрать отдельную зону и использовать основное место.

СВЯЗЬ С CODEX
Это наблюдатель: программирование и ответы остаются в чате Codex.
Консоль в игре пока не отправляет сообщения в этот чат.
Codex явно передаёт статусы через codex-progress.mjs. Пример вызова для агента:
runtime\node.exe codex-progress.mjs --key chat/task --title "Моя задача" --state reading --activity "Изучаю код" --optional
После пяти минут без обновлений персонаж показывает отсутствие свежего статуса.
Репозитории, ключи и исходники для отображения статусов не нужны.

МОСТ И НАСТРОЙКИ
Start-Bridge.cmd запускает локальный observer на 127.0.0.1:7878. Если такой observer
уже работает (например, от прежнего запуска AgentCraft), он используется повторно.
Stop-Bridge.cmd останавливает только мост, запущенный этим пакетом, и сохраняет состояние.
Состояние пакета: data/portable; журнал: logs. Не запускай два экземпляра на одном порту.
Настройки клиента: config/agentcraft-client.json внутри папки игры. Перезапусти игру после изменений.
Отладочный DevBridge и автоматическое открытие мира в обычном моде выключены.
В отдельной проверке Temurin 25.0.4.1 завершалась с нативной ошибкой JVM; если игра
закрывается на загрузке без отчёта Minecraft, выбери проверенную Java 25.0.2 в лаунчере.
Свой звук, настройки паузы, сложность, время, погода и точка появления мира сохраняются.
Настройки рабочего места: agentcraft-workspace.json внутри сохранения мира.
Поддерживается одиночная игра в обычном измерении, один Codex и одно активное рабочее место.

ПОСТРОЙКИ
Дом/остров можно построить самому или импортировать отдельно совместимыми средствами Minecraft.
Сторонние постройки не включены в этот пакет; встроенного импорта .schem пока нет.
Готовые cabin/studio остаются доступны в настроенном мире прежнего лаунчера AgentCraft.

Этот вариант основан на AgentCraft (MIT): https://github.com/OneBurned/agentcraft-odex
Лицензии AgentCraft, Node и библиотек находятся в licenses; лицензия Fabric API — в его JAR.
Сторонние схемы построек в пакет не входят.
