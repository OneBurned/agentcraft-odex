AgentCraft Codex 0.4.7 — Windows, Minecraft Java 26.3

НОВОЕ В 0.4.7
В карточках Codex и Клавы кнопка «Сообщение» открывает поле прямо в карточке.
Напиши текст и нажми Enter или «Отправить»; история и ответы видны в журнале персонажа.
Сообщение Codex приходит в подключённый чат, сообщение Клаве получает настоящий Claude Code.
В консоли: @Клава привет, @Claude текст, @Codex текст; имена персонажей поддерживаются после переименования.
Клава обсуждает план и результаты ревью, получает недавнюю историю, карточки и общие заметки.
Без настроенного рабочего пространства она не читает файлы. Код Клава не меняет.
Ревью и разговор Клавы не запускаются одновременно.
Дополнение моста: постоянное рабочее пространство Клавы с CLAUDE.md, PROJECTS.md и MEMORY.md.
WORKSPACE.md содержит обновляемую инструкцию инструментов. Установщик исходного проекта
поддерживает --update: сохраняет личные файлы, делает резервную копию и добавляет недостающие настройки.
Для ревью доступны полный список изменённых файлов коммита и чтение удалённых файлов из истории.
Примеры инструкций — в klava-template. Настроенный профиль может подключить чтение исходников
и GitHub выбранных проектов через отдельный сервер; доступ без явной настройки не включается.
GitHub использует локальный вход gh. Произвольные команды, push, merge и запись в проекты недоступны.
Инструкция подключения — docs/CODEX_OBSERVER.md исходного проекта. Существующий мод 0.4.7 совместим.
Общий разговор игры и Claude Code включается отдельной настройкой conversation.json.
Подготовка из исходного проекта: tools/configure-klava-conversation.mjs; она сохраняет существующую
сессию и добавляет ярлыки Continue-Klava.cmd, Open-Klava-Code.cmd и Return-Klava-To-Game.cmd.
Терминал нужно закрыть перед возвращением в игру. После Code нужен явный возврат через ярлык.
Обычные проекты Chat/Cowork не показывают эту историю. Подробности — в той же инструкции.
Пауза/Продолжить/Стоп управляют только выбранным агентом. Без задачи «Продолжить» снимает личную паузу.
Продолжение прерванной карточки возобновляет именно её; всю очередь запускают отдельно в пульте.
Пауза разговора завершает текущий процесс Claude, продолжение заново получает ответ с сохранённым контекстом.
Стоп убирает ожидающий ответ, сохраняя историю. Неподходящие кнопки недоступны; ошибки отправки сохраняют текст.
Для обновления нужны новый мод И перезапуск обновлённого моста. Перед заменой мода закрой Minecraft.

НОВОЕ В 0.4.5
Танец у шеста дополнен остановкой, плавным поворотом спиной, двумя медленными приседаниями
и поворотом обратно. Затем агент продолжает круг; движение повторяется на противоположной стороне.
Приседания доступны всем агентам, отдельная настройка не нужна. Работа, вопрос, планирование
или прекращение музыки прерывают танец. У стандартной модели ноги без коленей, поэтому
приседание стилизованное: наклон ног и опускание корпуса с сохранением опоры на пол.
При обновлении с 0.4.4 нужен только новый мод; мост и настройки менять не требуется.

НОВОЕ В 0.4.4
Открытая вкладка «План» собирает включённых персонажей у назначенных мест планирования.
Закрытие вкладки возвращает обычное поведение. Реальные задачи продолжаются; вопрос игроку важнее сбора.
У каждого агента теперь до 32 мест отдыха: обычные точки и танцы у шеста.
Настройщик: ПКМ по агенту → Shift+ПКМ до «Отдых: танцы у шеста» → ПКМ по вертикальной цепи/забору.
Нужен столб высотой от 3 блоков, нижний блок на уровне ног, свободный пол 3×3 вокруг и место для головы.
Рядом (до 5 блоков от основания шеста) должен играть проигрыватель с пластинкой. Нотный блок не подходит.
Танцы доступны всем агентам только во время отдыха. Один шест занимает один персонаж.
Музыка закончилась, шест сломан или появилась работа — танец прекращается.
Пульт → Места → Отдых: нажимай строку списка для выбора точки; доступны добавление, перенос и удаление.
«Добавить танцы» и «Перенести» закрывают пульт: затем возьми Настройщик и отметь нужный блок.
Обычные места добавляются в список. Старое личное место отдыха сохраняется как первая точка.
При нескольких доступных местах выбор сохраняется примерно 30 секунд, затем может измениться.
Для перехода с 0.4.2/0.4.3 достаточно заменить мод при закрытой игре; мост не меняется.

НОВОЕ В 0.4.3
Настройщик назначает отдельные места выбранному персонажу:
ПКМ по агенту — выбрать его (имя и зона появятся в подсказке).
Shift+ПКМ по полу или в воздухе — следующая зона; ПКМ по полу/креслу — назначить.
ПКМ по другому агенту переключает получателя. Shift+ПКМ по агенту возвращает общие места.
Места сохраняются вместе с точками из пульта; при входе в мир агента надо выбрать заново.
Сначала нужен основной участок. Настройка — в творческом режиме одиночного обычного мира.
Назначение места не запускает задачи. Для обновления с 0.4.2 достаточно заменить мод при закрытой игре.

НОВОЕ В 0.4.0
Новый блок «Пульт AgentCraft»: команда, внешность персонажей, план, очередь, места и память.
Возьми его во вкладке AgentCraft или командой /give @s agentcraft:command_desk. Открой ПКМ.
Codex пишет код в подключённом чате; Claude Code проверяет сохранённые изменения.
Во вкладке «Команда» добавь Claude. В «Настройках» нажми «Войти / проверить вход» и заверши
вход в браузере. Встроенный в Claude Desktop командный Claude Code находится автоматически;
вход в Desktop сам по себе не означает вход в Code. Можно задать полный путь к CLI claude.exe.
«План» → добавь задачи или обсуди их через консоль → открой карточку → «В очередь».
«Очередь» → «Начать / продолжить». Доска: План / В очереди / В работе / Ревью / Нужно решение / Готово.
Ревью бывает автоматическим, по кнопке или выключенным. После замечаний Codex исправляет код;
после двух неуспешных проверок решение принимает пользователь. Вопросы — в пульте, на кафедре
или по клавише J. Персонаж подходит к игроку, если он доступен внутри рабочего участка.
Пауза и Стоп прерывают реального исполнителя. Изменения в файлах остаются. После перезапуска
моста очередь всегда на паузе; прерванную работу нужно проверить перед повтором.
Во «Внешности»: встроенный скин/свой PNG 64×64 до 512 КБ, руки, внешний слой, подписи, цвет имени.
Изменения видны в предпросмотре и сохраняются кнопкой «Применить». Свой PNG задаётся полным путём.
Во вкладке «Места» встань на нужную точку и назначь её Codex или Claude; нужен участок Настройщика.
Общие заметки и отчёты ревью хранятся в библиотеке/каталоге. Ревью проверяет diff, тесты не запускает.
Для обновления нужны новый мод И новый мост. Закрой Minecraft, останови старый мост, установи
мод и запусти новый мост. Данные старого пакета переносить вместе с папкой data; настройки игры сохранять.

   C:\Program Files\Java\jdk-25.0.2\bin\javaw.exe

   Node входит в архив. Для обычного общения достаточно Codex; для ревью нужен вход в Claude Code.

КАК ОБУСТРОИТЬ CODEX
В творческом инвентаре открой вкладку AgentCraft, возьми Настройщик, Монитор,
Доску задач, Консоль и при желании Индикатор состояния.

Стол и кресло строй из любых обычных блоков. Настройщиком отметь место, где должен
находиться Codex: ПКМ по свободному полу или по креслу из ступеньки.
По умолчанию выбрано «Рабочее место» — его нужно отметить первым.
Shift + ПКМ переключает назначение: чтение, проверки, консоль, ревью, планирование,
отдых, ожидание ответа. Затем ПКМ по полу/креслу задаёт место выбранной зоны.
Для положения на полу Codex смотрит в ту же сторону, что и ты; на кресле — вперёд от спинки.

Поставь монитор, доску и консоль обычным способом. Мониторы и индикаторы без привязки
подключаются к Codex в течение секунды в пределах 32 блоков от рабочего места,
по высоте — 16. Доска расширяется соседними панелями; все панели должны смотреть в одну сторону.
Оставь проходы между зонами и место сбоку от кресел. Многоэтажные зоны требуют лестниц.
Перенос стола/кресла: отметь новое место Настройщиком. Экраны можно ломать и ставить заново.
Необязательные зоны, пока не назначены, используют основное рабочее место.

Команды для точного выбора:
/agentcraft workspace desk
/agentcraft workspace library
/agentcraft workspace testbench
/agentcraft workspace terminal
/agentcraft workspace mergestation
/agentcraft workspace meeting
/agentcraft workspace lounge
/agentcraft workspace user
Команда отмечает блок под прицелом не дальше 8 блоков.
/agentcraft workspace remove lounge — убрать отдельную зону и использовать основное место.

СВЯЗЬ С CODEX
ПКМ по консоли (или клавиша `, обычно физическая Ё) открывает журнал и строку ввода.
Напиши задачу обычным текстом, нажми Enter. Ответы на уточнения пиши туда же.
Сообщение передаётся в заранее подключённый существующий чат приложения Codex.
Подтверждение «Доставлено» означает доставку, а не завершение задачи.
Публичные сообщения и завершённые ответы Codex возвращаются в консоль и на монитор;
проверка новых ответов происходит раз в 5 секунд. При занятом чате сообщение может ждать.

Первое подключение: в нужном чате Codex попроси «Подключи этот чат к AgentCraft».
Codex выполняет runtime\node.exe connect-codex-chat.mjs из распакованного пакета.
Команда требует окружение текущего чата Codex; из обычного терминала она не выбирает чат сама.
Привязка хранится локально в %USERPROFILE%\.agentcraft\codex-chat.json и общая для мостов этого ПК.
Для отключения переименуй этот файл. После перезапуска/обновления приложения Codex может
потребоваться повторное подключение из чата. Если ответа о доставке нет, сначала проверь чат,
затем решай, повторять ли отправку: мост сам не повторяет сообщения с неизвестным результатом.
Приложение Codex должно быть открыто. Codex работает в существующем чате; Claude запускается для ревью из пульта.
Подтверждения доступа к инструментам остаются в приложении Codex; из игры их принять нельзя.
Журналы команд, скрытые рассуждения и вся старая история в игру не переносятся.
Это локальная интеграция со встроенными app-tools текущей версии Codex; обновление приложения
может потребовать обновления моста. Порт 7878 нельзя открывать в интернет: он доверяет процессам ПК.

КОМАНДЫ ИГРОВОЙ КОНСОЛИ
/help — доступные команды
/help blocks или /blocks — назначение всех блоков
/chat — подключённый чат и состояние связи (также показывает текущие задачи)
/status — задачи и состояние Codex
/sound on или /sound off — звуки уведомлений
/clear — очистить локальные строки консоли (общий журнал сообщений остаётся)
/repos — подключённые проекты
Обычный текст, @Codex текст и /goal текст — отправить сообщение в подключённый чат.
Enter — отправить; Shift+Enter — новая строка; Tab — дополнить; стрелки — история; Esc — закрыть.
/pause — прервать реальное выполнение задачи; /resume — продолжить её из сохранённого контекста.
/stop — остановить выполнение и удалить ожидающие сообщения этого чата.
Эти же действия доступны в карточке персонажа: Пауза / Продолжить, Стоп.
Это прерывание запуска Codex, а не заморозка процесса: уже выполненные изменения сохраняются.
Успех показывается после проверки остановки. При ошибке связи проверь состояние в Codex.
/spawn и /task относятся к самостоятельным агентам исходного AgentCraft. Для нового пула используй пульт.
/answer отвечает на вопросы пула, обычные вопросы из переписки — обычным текстом. /diff не показывает изменения чата.
Команды /agentcraft workspace, /agentcraft place и /gamemode вводятся в обычном чате Minecraft (T).
Кнопка «Сообщение» открывает поле прямо в карточке выбранного агента. Шрифт сообщений уменьшен
на 25%; в карточке сообщения переносятся целиком, колесо мыши над журналом прокручивает историю.

ЗНАЧЕНИЕ БЛОКОВ
Пульт AgentCraft — настройка команды, внешности, планирование и запуск очереди с ревью.
Монитор — журнал работы и ответы Codex; автоматически подключается возле рабочего места.
Доска задач — задачи по состояниям; ПКМ открывает карточку, панели одного направления объединяются.
Консоль — ввод задач и журнал переписки.
Индикатор — цветовое отображение состояния Codex.
Кафедра решений — вопросы по задачам пула (J); разрешения инструментов подтверждаются в Codex.
Архив и каталог — общие заметки и отчёты ревью; ограниченный контекст передаётся обоим исполнителям.
Стол ревью — просмотр изменений рабочих копий AgentCraft; в observer таких копий нет.
Glow Panel / Glow Strip — светильники (яркость 15 и 12).
Plaster Panel / Frame — светлые стены и рамки; Walnut Panel / Trim — деревянная отделка.
Terracotta Tile — плитка; Oak Parquet — дубовый паркет. Это декоративные строительные блоки.
Настройщик — предмет выбора общих и персональных мест. ПКМ по агенту выбирает получателя.
Для начала хватит основного места, монитора и консоли.

СТАТУСЫ РАЗРАБОТКИ
Codex явно передаёт статусы через codex-progress.mjs. Пример вызова для агента:
runtime\node.exe codex-progress.mjs --key chat/task --title "Моя задача" --state reading --activity "Изучаю код" --optional
При начале обработки сообщения Codex идёт к столу. Проверка чата выполняется раз в пять секунд.
Явные этапы (чтение, правка, тесты) направляют его к соответствующим назначенным местам.
При ожидании ответа/подтверждения он идёт к месту общения. После завершения ответа остаётся
у стола десять секунд и возвращается отдыхать; новая работа отменяет этот уход.
Обычный вопрос в тексте ответа требует явного статуса waiting_user от Codex.
После пяти минут без подробных обновлений он остаётся у стола, если чат ещё обрабатывает ответ;
иначе показывает отсутствие свежего статуса. Потеря связи или прерывание не означают успех.
Доска и шкала задач отражают явно переданную работу, а не каждое сообщение в чате.
Репозитории, ключи и исходники для отображения статусов не нужны. Отправка сообщения сама по себе
не означает начало/завершение работы — смотри подтверждение и ответ Codex.

МОСТ И НАСТРОЙКИ
Start-Bridge.cmd запускает локальный observer на 127.0.0.1:7878. Если такой observer
уже работает (например, от прежнего запуска AgentCraft), он используется повторно.
Stop-Bridge.cmd останавливает только мост, запущенный этим пакетом, и сохраняет состояние.
Состояние пакета: data/portable; журнал: logs. Не запускай два экземпляра на одном порту.
Настройки клиента: config/agentcraft-client.json внутри папки игры. Перезапусти игру после изменений.
Отладочный DevBridge и автоматическое открытие мира в обычном моде выключены.
В отдельной проверке Temurin 25.0.4.1 завершалась с нативной ошибкой JVM; если игра
закрывается на загрузке без отчёта Minecraft, выбери проверенную Java 25.0.2 в лаунчере.
Свой звук, настройки паузы, сложность, время, погода и точка появления мира сохраняются.
Настройки рабочего места: agentcraft-workspace.json внутри сохранения мира.
Поддерживается одиночная игра в обычном измерении, Codex и Claude, один активный участок с отдельными местами.

ПОСТРОЙКИ

Готовые cabin/studio остаются доступны в настроенном мире прежнего лаунчера AgentCraft.
